## 遊び方

GitHub Pages の URL を開き、作品カードを選ぶだけです。
画面（テキストボックス）をタップ／クリックで読み進めます。

## 画像の差し替え方法

画像はすべて `assets/` フォルダ内のプレースホルダ（SVG）です。差し替えは2通りあります。

1. **ファイル差し替え（簡単）**: `assets/` 内のファイルを、同じファイル名のまま自分の画像に置き換える
   - 例: さくらの立ち絵 → `assets/sakura_char.svg`
2. **パス変更**: `index.html` の各作品データにある `images` と `cover` のパスを、自分の画像ファイル（例: `assets/sakura_char.png`）に書き換える

対応する場面はファイル名で分かります（`_cover` = 表紙、`_char` = 立ち絵、それ以外は背景）。
画像が読み込めない場合は自動的にグラデーション表示にフォールバックするので、壊れることはありません。

## シナリオの編集

`index.html` 内の `GAMES` 配列が全作品のデータです。
`text` を書き換えればセリフが変わり、`choice` で選択肢、`branch` で好感度（`love`）分岐、`r18: true` の行が文章のみのR18シーンになります。

## VN Arcade UI（新エンジン版）

2026-11-11 の大型更新で、エンジンとUIを全面刷新しました。設計は `DESIGN_SPEC.md` を参照。

### ファイル構成
- `index.html` … 画面の構造のみ
- `style.css` … デザインシステム（共通スケルトン＋作品ごとのテーマ変数）
- `engine.js` … ゲームロジックとUI制御
- `data.js` … シナリオデータ（`GAMES` 配列、旧版から無改変で分離）

### 新機能
- 作品ごとのタイトル画面（キービジュアル＋立ち絵＋ロゴ、START/CONTINUE/LOAD/CONFIG/EXTRA）
- セーブ/ロード：12スロット×10ページ＋クイックセーブ、サムネイル・日時・本文プレビュー付き
  （旧形式 `vn_save_<作品ID>` のセーブも「旧セーブを読む」から読み込み可能）
- コンフィグ：文章速度、オート待機、文字サイズ、スキップ対象（既読のみ/すべて）、既読色分け、
  エフェクト切替、フルスクリーン、ボスキー（Backspaceで事務文書風の偽装画面）
- バックログ：行タップでその場面へジャンプバック（フラグも復元）
- EXTRA（エンディング到達で解放）：分岐フローチャート（到達済みノードから回想再生）、
  ギャラリー（作中で表示された素材だけ解放）、エンディング達成状況
- 表情差分：シナリオノードに `face: "smile"` のように指定可能。未指定時は本文の感情語から
  自動で差分に切り替える演出レイヤーあり（対応素材がある作品のみ）

### 画像の差し替え方法（新版）
生成済み素材は `engine.js` の `ASSET_OVERRIDES` で作品ごとに割り当てています。
- 背景/KVを差し替える場合：同じパスのファイルを置き換えるか、`ASSET_OVERRIDES` のパスを変更
- 生成元PNGは `assets-raw/` に保管。Web配信用は幅1600pxのJPEG（画質84）に変換して配置
- 未生成の作品・場面は従来のSVGプレースホルダにフォールバックします
